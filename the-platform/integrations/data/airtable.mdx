## Overview

Read and write Airtable records from your Plura workflows. Look up a caller's record mid-conversation, log a new lead the moment a call ends, or update a row when a deal moves forward. Call actions with `automationType: "airtable"` from any workflow node that supports automations.

## Authentication

- Connect your Airtable account to your Plura workspace before you use these actions.

## Available Actions

| Action | What it does | What you provide |
|--------|--------------|------------------|
| List Bases | Lists the Airtable bases your connection can reach | Nothing |
| List Tables | Lists the tables in a base | The base |
| List Records | Returns records from a table | The base and table |
| Find Record | Finds records that match an Airtable formula | The base, table, and formula |
| Create Record | Adds a new record to a table | The base, table, and field values |
| Update Record | Changes fields on an existing record | The base, table, record ID, and the fields to change |
| Delete Record | Deletes a record | The base, table, and record ID |

## Using Airtable in a workflow

1. In the workflow editor, add Airtable to your workflow.
2. Pick the action you want.
3. Fill in the fields the editor shows for that action. To use values from the call, like the caller's name or phone number, map them in with custom fields (see Custom Fields in the [Integrations Overview](/the-platform/integrations/overview)).

To find a record by phone number, use **Find Record** with a formula like `{Phone} = '+15551234567'`. Use your table's own field name in the curly braces.
